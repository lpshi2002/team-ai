## Question

Which harness should be the actual team-member design: the lighter document-memory-context-reasoning loop, or the fuller deliberation graph structure?

## Decision

Use the lighter four-component harness as the body:

1. Document Perception
2. Team Memory
3. Context Compiler
4. Reasoning Harness

Add only the safety fields from the richer design: `authority`, `status`, `source_refs`, `related`, temporal validity, and AI self-reinforcement prevention.

## Rationale

- A useful AI teammate needs current project awareness and good question-time context more than a complete meeting ontology.
- Fewer extraction layers keep source distance short and make errors easier to trace.
- Detailed discussion roles can be reconstructed from source text when needed instead of pre-labeling every sentence.
- AI-inferred knowledge should be usable, but not self-proving.

## Strongest Countercase

The richer deliberation graph can preserve more nuance when extraction is perfect.

## Why The Decision Holds

Extraction will not be perfect. A simpler memory schema with source references, authority, status, and related links gives most of the team-member benefit while reducing stale derived data and error propagation.
